# VIMEK — Mã nguồn

Mã nguồn ứng dụng nằm trong [VIMEK](VIMEK/).

- [engine](VIMEK/engine/): xử lý Telex, VNI và các quy tắc gõ.
- [windows](VIMEK/windows/): ứng dụng Win32, tray và project Visual Studio.
- [macOS](VIMEK/macOS/): ứng dụng Cocoa, menu bar và helper khởi động.
- [linux](VIMEK/linux/): ghi chú nền tảng; chưa có ứng dụng Linux.

Hướng dẫn build: [README](../README.md), [macOS](../macOS_Build.md).
Nguồn gốc, tác giả và giấy phép: [NOTICE](../NOTICE.md), [GPL-3.0](../LICENSE).
